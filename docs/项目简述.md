# 我给 AI 装了一部红色座机

**一部老式红色座机 + 一个语音网关，让 AI 变成能打电话的同事：我拿起听筒说话，它干完活会打回来。**

---

## 它是干嘛的

平时用 AI 干活，得坐在电脑前打字。想交代一句事，手得离开正在做的事、切窗口、敲字、发送。

现在改成这样：

```
拿起听筒，说一句话，放下。
   ↓
话自动变成文字，发给 AI
   ↓
AI 开始干活，我可以走开
   ↓
干完了，电话响铃 —— 回来看看结果
```

**拿起就能说，放下就算说完，干完活还会响铃叫我。**

---

## 为什么用电话

不是怀旧，是电话这个形态刚好合适：

- **拿起听筒** = 一个不会误触的动作。比喊"嘿某某"这种唤醒词可靠多了
- **放下听筒** = 明确的"我说完了"。不用按任何按钮
- **它会响铃** = 这是普通麦克风做不到的 —— 麦克风只能听，电话能主动找你

最后一条是关键。**我要的不是"能说话的工具"，而是"能被我忘掉、等它自己来找我的工具"。**

## 它跟"语音助手"有什么不一样

| | 智能音箱 / 手机语音 | 这个 |
|---|---|---|
| 怎么开始 | 喊唤醒词，或者点按钮 | **拿起听筒** |
| 怎么结束 | 等它自己判断 | **放下听筒** |
| 干完活 | 它不知道你还在不在 | **打电话响铃叫你** |
| 你的话去哪了 | 上传到云端 | **只在自己电脑里** |

最后一条是硬要求：**说的话一个字都不出这台电脑**，识别全在本机完成。
