# 红色座机语音终端 · 采购与接线清单

> 目标：买一台红色模拟座机 + 一个转换件，把听筒变成电脑的麦克风+扬声器。
> 配套：电脑端语音链路已跑通（CapsWriter + SenseVoice，见项目计划书 §附录A）

---

## 一、买哪台座机？（这是决定成败的一步）

### 唯一硬性要求：**听筒是"可拔插"的，插头是 4 芯（4P4C / RJ9）**

判断方法（看商品图或问客服）：
- ✅ **听筒通过一根螺旋电话线与机身相连，线的两端都能拔下来** → 这就是 4P4C，能直接利用
- ❌ 听筒线是焊死在机身里的 → 要拆机焊接，工程量翻倍
- ❌ 无绳/子母机（听筒和机身靠无线连接）→ **完全不可用**，没有音频线可接
- ❌ 一体式"电话造型蓝牙音箱"→ 不可用

### 年代：**买 1995 年以后生产的**

| 年代 | 听筒话筒类型 | 能否直连声卡 |
|---|---|---|
| 1980 年代及更早 | **碳精话筒**（需通话电流才工作） | ❌ 要改电路、换话筒 |
| 1990 年代中前期 | 过渡期，混用 | ⚠️ 要试 |
| **1995 年以后 / 现代** | **驻极体话筒** | ✅ **直接可用**（声卡 Mic In 自带偏置供电，正好喂它） |

👉 **结论：年代越新越好用。** 我们要的是"看起来像老电话 + 内部是能直连声卡的现代听筒"。
所以**复古造型的现代座机**（淘宝上大量）反而是最佳选择——外观满足情怀，内部满足技术。

### 推荐型号（按性价比排序）

| 推荐 | 说明 | 参考价 |
|---|---|---|
| **宝泰尔（BOTEL）T121 红色** | 有明确红色款，按键式标准桌面座机，工程成熟、听筒可拔插 | 40–80 元 |
| **宝泰尔 T077 系列** | 同品牌经典款，淘宝/京东在售，配件好找 | 40–90 元 |
| **美思奇 复古款（红）** | 复古造型，按键拨号，家用/办公室通用 | 50–100 元 |
| **复古拨号盘造型座机（红）** | 想要"拨号盘"外观的选择（多为装饰性拨号盘+按键拨号） | 100–200 元 |
| 二手经典款 | 咸鱼淘 90 年代红机（务必先确认听筒可拔插+话筒类型） | 30–150 元 |


## 二、怎么连到笔记本？（三条路线，按动手量排序）

### 路线 A：买成品适配器（最省事，成功率 95%）

**RJ9 转 USB 耳机适配器 / USB 话务盒**——它本来就是干这个的（把座机听筒接到电脑当 USB 耳麦用）。

```
电话听筒 ──4P4C线──► [RJ9→USB 适配器] ──USB──► 笔记本
```

| 项目 | 说明 |
|---|---|
| 搜索词 | `RJ9转USB 耳机适配器`、`USB 话务盒`、`电话听筒转USB`、`USB 软电话适配器` |
| 价格 | 100–330 元（海淘 StarTech UR9-HEADSET-ADAPTER 约 ¥220–330） |
| 优点 | Windows **免驱**，直接多出一个"麦克风+扬声器"，全双工 |
| 接线 | 把听筒从座机上拔下来，插进适配器的 RJ9 母口，USB 插笔记本。**零焊接** |

⚠️ 下单前问客服一句：**"这个适配器插上电脑，Windows 的『录音设备』里能直接看到一个麦克风吗？"**（防买到走私有驱动、不暴露成声卡的型号）

### 路线 B：DIY（最便宜，15–45 元，需要电烙铁）

```
电话听筒 ──4P4C线──► 剪线剥皮 ──► [CM108 免驱 USB 声卡] ──USB──► 笔记本
```

**零件**：
| 零件 | 搜索词 | 价格 |
|---|---|---|
| 免驱 USB 声卡（CM108 芯片，带粉色 Mic In + 绿色耳机口） | `USB声卡 免驱 CM108` | 10–30 元 |
| 4P4C 母座 或 备用螺旋线 | `4P4C 母座`、`电话弹簧线 4芯` | 5–15 元 |

**接线（4P4C 标准线序）**：
```
引脚 1 = MIC+       → 声卡 粉色 Mic In 的 信号端
引脚 2 = SPEAKER    → 声卡 绿色 耳机口 的 左/信号端
引脚 3 = SPEAKER    → 声卡 绿色 耳机口 的 地/端
引脚 4 = MIC-       → 声卡 粉色 Mic In 的 地端
```
⚠️ 不同品牌线序偶有出入。**不确定时用"试"的办法**：
接好后打开 Audacity（或直接用 Windows 录音机）录 5 秒，对着话筒说话——
- 有清晰波形 → 接对了
- 波形极小几乎看不到 → 多半是把喇叭当话筒接了，**把麦克风的两根线对调**再试
（听筒喇叭确实能当话筒用，但灵敏度低得多，这就是分辨依据）

**安全注意**（社区实践总结）：
1. **先把系统音量调到很低**再插入（麦克风增益和输出音量都调低）
2. 听筒的阻抗和普通耳麦不一样，理论上有损伤声卡的风险（实际风险低，但别一上来就最大音量）
3. 声卡 Mic In 的偏置电压（2–5V）**正好**能给驻极体话筒供电，不用另加电阻
4. 如果用的是老式碳精话筒听筒，**必须**在信号线上串一个 **0.1–1µF 隔直电容**（碳精话筒不需要偏置，直连可能损坏声卡）

### 路线 C：话机整机接网关（电话感最强，400–700 元，暂不需要）

```
话机 ──RJ11──► [FXS 语音网关] ──网线──► 笔记本(SIP)
```
只有想保留"真拨号音、机械铃真响"时才需要。买网关必须认准 **FXS**（接话机），别买 FXO（接外线）。见项目计划书 §4。

## 三、关于"连接到笔记本"的几个要点

| 问题 | 答案 |
|---|---|
| 用哪台电脑？ | **必须先确认 CapsWriter 跑在哪台**。你的 WS63 用 `--profile server` 跑服务端在本机（本机推理），所以**链路线接到这台 WS63 笔记本上**最合适，零配置 |
| 笔记本接口够吗？ | 路线 A/B 都只占一个 USB-A 口。WS63 有 3×USB-A，够用 |
| 声音从哪出？ | 路线 A/B 下，电脑的音频输出会跑到"听筒"上。日常提示音建议仍在系统设置里保持主扬声器，只听筒作为"AI 回话"的出口（后续 P3 做 TTS 时要显式指定输出设备） |
| 会不会和现有麦克风冲突？ | 不会。CapsWriter 客户端默认用系统默认输入设备；接上听筒后，在 Windows 声音设置里把**默认输入设备改成这个 USB 声卡**即可 |
| MacBook 能不能用？ | 路线 A 的 USB 适配器通常兼容 macOS，但 CapsWriter 服务端**不支持 macOS**（作者明确说明）。所以主链路还是走这台 WS63 |

## 五、到货后的接线与验证步骤

1. **拆听筒线**：把听筒的螺旋线从座机上拔下来
2. **接适配器/声卡**（按 §二对应路线）
3. **验证 Windows 能看见设备**：设置 → 系统 → 声音 → 输入/输出，应出现新的"USB Audio Device"
4. **设为默认输入**：把这个新设备设为默认麦克风
5. **听筒出声测试**：播放一段音频，应能从听筒听到（把该设备也设为默认输出，或播放器里选它）
6. **接进 CapsWriter**：什么都不用改，客户端会自动跟系统默认输入设备走；按住 CapsLock 对着听筒说话试一次
7. **确认无误后**，再考虑 P2：用叉簧开关（提机=按住 CapsLock、挂机=松开）实现"提机即录、挂机即上屏"

## 六、为什么不让整机接电话线（避免走弯路）

话机需要局端 **−48V 馈电**（否则听筒完全静音）和 **20–25Hz / 60–90V 铃流**（否则不响铃），
电脑和任何"模数转换器"都给不了这两样。所以**只取听筒**是最短路径——听筒本质就是"驻极体话筒 + 动圈喇叭"，与普通耳麦电气上一致。
若一定要让话机整机工作（有拨号音、能真响铃），就得买 FXS 语音网关，那是另一条更贵但更"真"的路线。
